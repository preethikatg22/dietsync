🚀 AWS Starter Kit

A tiny demo of two AWS services wired into a website: Amazon S3 for file storage and Amazon Bedrock (Nova Pro) for AI. Copy these patterns into your own site!

📦 Amazon S3 — Upload a file

Pick any file (image, pdf, text) and store it in your S3 bucket.

🤖 Amazon Bedrock Nova Pro — Ask the AI

Type a question or prompt and let Nova Pro answer.
